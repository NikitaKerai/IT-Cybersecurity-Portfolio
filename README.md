# 🚀 Featured Projects

## 🏎️ F1 Telemetry Cybersecurity Risk Analysis

A Python-based cybersecurity research and simulation project investigating how cyberattacks affecting Formula One telemetry data could influence race-strategy decisions and operational outcomes.

The project uses historical 2025 Formula One race data and introduces controlled attack scenarios against telemetry data.

### Cyberattack Scenarios

- Telemetry Spoofing
- Data Tampering
- Telemetry Delay
- Denial of Service (DoS)

### Cybersecurity Analysis

The project applies:

- STRIDE Threat Modelling
- CIA Triad Analysis
- NIST-style Risk Assessment
- Attack Impact Analysis
- Operational Risk Analysis

The simulations investigate how compromised telemetry integrity and availability can affect pit-stop recommendations, strategy decisions and simulated race-position outcomes.

### Key Finding

The analysis demonstrates that cybersecurity risk is not limited to system outages.

A system may remain operational while compromised or delayed data influences downstream decisions. This highlights the importance of telemetry integrity, validation, anomaly detection and resilient data pipelines in data-driven environments.
