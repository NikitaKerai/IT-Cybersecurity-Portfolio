# 🏠 Analysis of IoT Cyber Attacks in Smart Homes

## 📌 Project Overview

This project is based on my BSc dissertation, **“Analysis of IoT Cyber Attacks in Smart Homes.”**

The project investigated cybersecurity risks affecting Internet of Things (IoT) devices within smart home environments, with a particular focus on **Distributed Denial of Service (DDoS) attacks** and the use of an **Intrusion Detection System (IDS)** as a defensive security measure.

The research explored how attacks against IoT environments can affect the availability and security of connected devices, as well as how monitoring and detection mechanisms can help identify malicious activity.

---

## 🎯 Project Objectives

The main objectives of the project were to:

- Investigate cybersecurity risks affecting IoT devices in smart homes.
- Analyse the impact of DDoS attacks on IoT environments.
- Explore how an Intrusion Detection System (IDS) can be used to detect suspicious or malicious network activity.
- Identify security measures that can improve the resilience of smart home IoT environments.

---

## ⚔️ DDoS Attack Analysis

Distributed Denial of Service (DDoS) attacks attempt to overwhelm a system, service or network with large volumes of traffic.

IoT environments can be particularly relevant to DDoS attacks because compromised IoT devices can be incorporated into botnets and used to generate malicious network traffic.

As part of the project, the potential impact of DDoS activity within a smart home/IoT environment was investigated, particularly in relation to the **availability of connected devices and services**.

---

## 🛡️ Intrusion Detection Systems (IDS)

The project also investigated the role of an **Intrusion Detection System (IDS)** in improving IoT security.

An IDS monitors network or system activity to identify behaviour that may indicate an attack or other security threat.

The research considered how intrusion detection could be used within an IoT environment to provide greater visibility of network activity and help identify potential attacks such as DDoS activity.

---

## 🔐 Security Considerations

The project highlighted the importance of implementing appropriate security controls within IoT and smart home environments, including:

- Monitoring network activity for suspicious behaviour.
- Using intrusion detection to identify potential attacks.
- Keeping IoT devices and firmware updated.
- Using secure authentication and strong credentials.
- Securing networks containing IoT devices.
- Reducing unnecessary exposure of IoT devices and services.
